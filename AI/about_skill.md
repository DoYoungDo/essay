## AI专业词概念-skill

### 什么是Skill？

Skill（技能）是面向特定任务的指令包：把完成某类任务所需的工作流程、步骤、约束和参考资料固化成一个文件夹（核心是 SKILL.md），交给 AI Agent。Agent 平时只登记每个技能的名称和触发时机，任务匹配时才把完整内容加载进上下文。

### Skill的基本构成

1. **SKILL.md**：技能主体，写明适用场景、触发条件、执行步骤
2. **脚本/资源**：配套的可执行脚本、模板、参考文档（可选）

### Skill的价值

1. **按需加载**：不占用日常上下文，触发时才展开
2. **经验复用**：把复杂任务的最佳实践沉淀下来，一次编写、反复使用
3. **独立维护**：每个技能自成文件，可单独增删，不互相干扰

### 与Prompt的关系

prompt 是一次性的指令，skill 是结构化、可复用、按需加载的 prompt 集合，相当于把 prompt 工程从"对话里"搬到了"文件里"。

### 总结

skill 简单概括就是 Agent 的技能包：平时收在工具箱里，碰到匹配的任务才取出来用，如 Claude Code 和 uni-agent 的 skills 机制。
